- همهٔ این تنظیمات **برای هر پنل جداگانه** ذخیره می‌شوند.
- کنار بعضی دکمه‌ها وضعیت فعلی داخل پرانتز آمده است و با هر بار زدن عوض می‌شود.
- همین تنظیمات در [پنل مدیریت وب](/docs/webapp/admin-panel) هم وجود دارد. بعضی موارد، مثل بازهٔ حجم و روز خرید دلخواه، فقط در پنل وب قابل ویرایش‌اند.

## 🎨 استایل دکمه (خرید / لیست) [#style]

ظاهر دکمه‌ای که این پنل را نشان می‌دهد، هم در **خرید سرویس** کاربر و هم در **📉 وضعیت پنل ها**. فقط ظاهر را عوض می‌کند و روی عملکرد پنل اثری ندارد.

| گزینه | کار |
|--------|-----|
| ✏️ متن دکمه | متن دلخواه بفرستید، یا `/skip` تا نام پنل استفاده شود |
| آبی / سبز / قرمز / — | رنگ دکمه (`—` یعنی بدون رنگ) |
| 🖼 آیکون پریمیوم | یک ایموجی پریمیوم بفرستید تا کنار متن نمایش داده شود (یا `/skip` برای حذف) |
| 🧹 حذف آیکون | حذف آیکون |
| ♻️ ریست به نام پنل | برگشت متن، رنگ و آیکون به حالت پیش‌فرض |

## ⚡ فعال‌سازی پنل [#enable]

`⚡ فعال‌سازی پنل (✅/❌)` کلید اصلی پنل در ربات است. وقتی خاموش باشد، پنل از خرید سرویس و خرید نمایندگی کنار می‌رود. سرویس‌هایی که قبلاً روی پنل ساخته شده‌اند حذف نمی‌شوند. برای وقتی مناسب است که سرور در حال تعمیر است یا موقتاً نمی‌خواهید رویش بفروشید.

## 🛒 خرید سرویس / 🏢 نمایندگی [#sales]

دو کلید جدا برای همین پنل (پیش‌فرض هر دو روشن):

- **🛒 خرید سرویس**: آیا کاربران می‌توانند از این پنل کانفیگ بخرند.
- **🏢 نمایندگی**: آیا این پنل در **خرید پنل نمایندگی** نمایش داده شود.

برای اینکه فروش واقعاً انجام شود، علاوه بر این کلیدها، **⚡ فعال‌سازی پنل** هم باید روشن باشد. کلیدهای سراسری **وضعیت فروش** و **فروش نمایندگی** در [تنظیمات ربات](/docs/admin/bot-settings) هم باید روشن باشند. مثلاً می‌توانید یک پنل را فقط برای نماینده‌ها نگه دارید.

## ✏️ نام [#name]

نام جدید را بفرستید. این نام در پیام‌ها و دکمه‌ها (اگر متن سفارشی برای دکمه نگذاشته باشید) نمایش داده می‌شود.

## 🔑 ورود [#auth]

`🔑 ورود (API Key)` یا `🔑 ورود (User/Pass)` نوع ورود فعلی را نشان می‌دهد. با زدنش سه گزینه دارید:

| گزینه | توضیح |
|--------|--------|
| 🌐 تغییر آدرس پنل | آدرس جدید فقط با دامنه یا آی‌پی و پورت و **بدون path**، مثل `https://panel.example.com:8000`. این آدرس بررسی زنده نمی‌شود، پس بعد از تغییر، صفحهٔ جزئیات را باز کنید تا مطمئن شوید وضعیت سرور خوانده می‌شود. |
| 👤 نام کاربری و رمز | نام کاربری و بعد رمز جدید. ربات اول وارد پنل می‌شود و فقط اگر موفق باشد ذخیره می‌کند. |
| 🔑 API Key | کلید جدید. این هم قبل از ذخیره امتحان می‌شود. |

رمز پنل رمزنگاری‌شده در دیتابیس نگه داشته می‌شود.

## 📦 گروه پیش‌فرض [#groups]

گروه‌هایی که **کاربران جدید** هنگام ساخت کانفیگ در آن‌ها قرار می‌گیرند. لیست گروه‌ها همان لحظه از پنل خوانده می‌شود. گروه‌ها را با زدن انتخاب یا لغو انتخاب کنید (✅) و **✅ تایید** را بزنید. **استفاده از همه گروه‌ها** یا انتخاب نکردن هیچ گروهی یعنی همهٔ گروه‌ها. این تغییر روی کاربرانی که از قبل ساخته شده‌اند اثری ندارد.

## 🧢 سقف خرید سرویس از این پنل [#purchase-limit]

حداکثر تعداد کانفیگ‌هایی که روی این پنل فروخته می‌شود. صفحه، تعداد کانفیگ‌های فعلی و سقف فعلی را نشان می‌دهد.

- **🔢 تعیین محدودیت جدید**: یک عدد صحیح مثبت بفرستید، مثلاً `500`.
- **♾️ نامحدود کردن**: حذف سقف (پیش‌فرض).

وقتی تعداد کانفیگ‌ها به سقف برسد، این پنل در لیست خرید نمایش داده نمی‌شود. این سقف به ظرفیت کاربرِ نماینده‌ها ربطی ندارد.

## 📱 دکمه‌های سرویس من [#service-buttons]

تعیین می‌کند کاربرانِ این پنل در صفحهٔ هر سرویس (در **سرویس‌های من**) کدام دکمه‌ها را ببینند. همهٔ دکمه‌ها در هر پنل به‌طور پیش‌فرض روشن (✅) هستند.

<Callout type="warn" title="کلید سراسری هم باید روشن باشد">
هر دکمه فقط وقتی به کاربر نشان داده می‌شود که **هم** کلید همین پنل **و هم** کلید سراسری همان دکمه در [⚙️ تنظیمات ربات](/docs/admin/bot-settings#service-tools) روشن باشد. کلیدهای سراسری به‌طور پیش‌فرض **خاموش‌اند**، پس در ربات تازه‌نصب، اول باید آن‌ها را روشن کنید.
</Callout>

|-----------|------------------------------|------|
| ⏰ خرید زمان | دکمه خرید زمان | فقط اگر برای پنل [پلن زمان اضافه](#extra-plans) تعریف شده باشد |
| ♾️ خرید حجم | افزایش حجم | فقط اگر پلن حجم اضافه تعریف شده باشد. برای پلن مصرف منصفانه نمایش داده نمی‌شود |
| 💎 تمدید سرویس | تمدید سرویس | برای سرویس تست نمایش داده نمی‌شود |
| 🔗 تغییر ساب | تغییر ساب | |
| ➕ لینک‌های دیگر | لینک‌های دیگر | |
| 🔗 تغییر لینک | تغییر لینک | |
| 🔗 کپی لینک | کپی لینک | |
| 🔘 QRcode | دریافت QR Code | |
| 🔎 واگذاری | انتقال کانفیگ | انتقال سرویس به کاربر دیگر |

### 🏢 دکمه‌های نمایندگی [#reseller-buttons]

زیر همان صفحه، دکمه‌هایی که نماینده‌های این پنل در **نمایندگی‌های من** می‌بینند. این‌ها جدا از دکمه‌های سرویس ذخیره می‌شوند و کلید سراسری ندارند. پیش‌فرض همه روشن است:

`🔑 نمایش رمز ورود` · `🔐 تغییر رمز عبور` · `🕹 فعال/غیرفعال سازی پنل` · `📊 گزارش مصرف` · `📦 محدودیت مصرف` · `👥 خرید ظرفیت کاربر اضافه` · `🗑 حذف نمایندگی`

برای «👥 خرید ظرفیت کاربر اضافه»، [خرید ظرفیت کاربر](#reseller-capacity) هم باید فعال باشد.

## 📊 نمایش [#display-mode]

ترتیب انتخاب پلن در خرید سرویس:

| حالت | برچسب دکمه | رفتار |
|------|-------------|--------|
| کلاسیک (پیش‌فرض) | `📊 نمایش (📋 کلاسیک)` | همهٔ پلن‌ها در یک لیست نمایش داده می‌شوند |
| زمان‌محور | `📊 نمایش (⏰ زمان)` | کاربر اول مدت را انتخاب می‌کند (مثلاً ۳۰ یا ۹۰ روزه) و بعد پلن‌های همان مدت را می‌بیند |

در حالت زمان‌محور، در [ساخت پلن → مدیریت پلن‌ها](/docs/admin/plans#duration-buttons) دکمهٔ **🎨 دکمه‌های مدت (زمان اول)** اضافه می‌شود تا متن و رنگ دکمهٔ هر مدت را تنظیم کنید.

## 📡 اطلاع‌رسانی [#notifications]

هشدار کم‌حجم و نزدیک‌شدن انقضا به کاربر:

- `📡 اطلاع‌رسانی (🤖)` (پیش‌فرض): خود ربات هر ۶۰ ثانیه کاربران پنل را بررسی می‌کند.
- `📡 اطلاع‌رسانی (🔔)`: پنل پاسارگارد از طریق وب‌هوک به ربات خبر می‌دهد. سبک‌تر و دقیق‌تر است و **پیشنهاد می‌شود**.

برای حالت 🔔 باید وب‌هوک را در خود پاسارگارد هم تنظیم کنید. راهنمای کامل: [اطلاع‌رسانی حجم و زمان](/docs/admin/panels/notifications).

## 📊 تمدید حجم [#renew-volume]

وقتی کاربر یک سرویس **حجمی** را تمدید می‌کند، حجم جدید چطور حساب شود:

| حالت | برچسب | محاسبه |
|------|--------|--------|
| ➕ جمعی (پیش‌فرض) | `📊 تمدید حجم (جمعی)` | حجم کل + حجم پلن. **مصرف ریست نمی‌شود.** |
| باقی+ریست | `📊 تمدید حجم (باقی+ریست)` | حجم **باقی‌مانده** + حجم پلن. **مصرف صفر می‌شود.** |

**مثال:** سرویس ۲۰ گیگ دارد و ۱۵ گیگ مصرف شده (۵ گیگ باقی). کاربر پلن ۳۰ گیگ را تمدید می‌کند:

- **جمعی**: حجم کل ۵۰ گیگ، مصرف همان ۱۵ گیگ، **باقی‌مانده ۳۵ گیگ**.
- **باقی+ریست**: حجم کل ۳۵ گیگ (۵ + ۳۰)، مصرف ۰، **باقی‌مانده ۳۵ گیگ**.

حجم قابل استفاده در هر دو حالت یکی است. فرقشان در درصد مصرفی است که پنل می‌بیند. اگر در پاسارگارد برای **درصد مصرف** وب‌هوک گذاشته‌اید، حالت **باقی+ریست** را انتخاب کنید. در حالت جمعی، مصرف قبلی باقی می‌ماند و هشدارهای درصدی دقیق نیستند.

پلن‌های **مصرف منصفانه** همیشه مستقل از این تنظیم تمدید می‌شوند: حجم برابر حجم پلن و مصرف صفر.

## 🔗 لینک ساب [#sub-link]

با هر بار زدن، بین سه حالت می‌چرخد. نتیجه را در پیام تایید می‌بینید:

| حالت | چه چیزی به کاربر نشان داده می‌شود |
|------|----------------------------------|
| اصلی + تانل (پیش‌فرض) | لینک ساب اصلی و، اگر [لینک تانل](#tunnel) تنظیم شده باشد، لینک تانل هم |
| فقط اصلی | فقط لینک ساب اصلی پنل |
| فقط تانل | فقط لینک تانل (اگر لینک تانل تنظیم نشده باشد، لینک اصلی نشان داده می‌شود) |

## 🔗 لینک تکی [#single-links]

علاوه بر لینک ساب، می‌توانید لینک تک‌تک کانفیگ‌ها را داخل پیام **خرید سرویس** و **دریافت تست** بگذارید. ایندکس‌ها از ۱ شروع می‌شوند و ترتیبشان همان ترتیب خروجی پنل است.

| ورودی | معنی |
|--------|------|
| `1,2,3` | لینک اول، دوم و سوم |
| `1-3` | بازهٔ اول تا سوم |
| `all` | همهٔ لینک‌ها |
| `0` | غیرفعال (همین کار را **🧹 غیرفعال کردن نمایش لینک تکی** هم می‌کند) |

بعد از ذخیره، در متن پیام خرید و تست از `{config_links}` یا `{config_links_with_txt}` استفاده کنید ([متن‌های ربات](/docs/admin/texts-keyboards)).

## 🌐 پیشوند نود [#node-prefix]

اگر نام نودهای پاسارگارد را با پیشوند مشخص کرده باشید، ربات با آن‌ها تشخیص می‌دهد کدام لوکیشن‌ها را روی فاکتور هر پلن نشان دهد (در حالت **خودکار** [لوکیشن‌های فاکتور](#locations)).

| پیشوند | برای |
|---------|------|
| `LT -` | نودهای حجمی |
| `HYB -` | نودهای ترکیبی (حجمی + نامحدود) |
| `UL -` | نودهای نامحدود |

- با زدن روی هر پیشوند، آن را انتخاب (✅) یا لغو (☐) می‌کنید.
- برای پلن **نامحدود حجمی**، نودهای `UL -` و `HYB -` نمایش داده می‌شوند. برای پلن‌های **حجمی** و **مصرف منصفانه**، نودهای `LT -` و `HYB -`.
- **پیشوندهای سفارشی** برای همهٔ پلن‌ها نمایش داده می‌شوند.
- وقتی حداقل یک پیشوند انتخاب کرده باشید، نودی که هیچ پیشوند انتخاب‌شده‌ای ندارد نمایش داده نمی‌شود. اگر هیچ پیشوندی انتخاب نکنید، همهٔ نودها نمایش داده می‌شوند.
- **➕ افزودن پیشوند سفارشی**: مثلاً `TUN -`. دقیقاً همان‌طور که در نام نود نوشته‌اید، حداکثر **۳۲ کاراکتر**، بدون ویرگول و تک‌خطی. پنل وب حداکثر **۲۰ پیشوند** برای هر پنل قبول می‌کند.
- **✅ نمایش پیشوندها / ❌ مخفی کردن پیشوندها**: اگر مخفی باشد، پیشوند از نام لوکیشن حذف می‌شود (مثلاً `LT - آلمان` به شکل `آلمان` نمایش داده می‌شود).

## 📍 لوکیشن‌های فاکتور [#locations]

بخش لوکیشن‌ها در فاکتور خرید این پنل:

| حالت | رفتار |
|------|--------|
| 🛰 خودکار (پیش‌فرض) | نام نودهای همین پنل، با فیلتر [پیشوند نود](#node-prefix) |
| ✍️ دستی | متن خودتان **دقیقاً همان‌طور که فرستاده‌اید** جای بخش لوکیشن فاکتور می‌نشیند (عنوان هم با خودتان است). اگر متنی ثبت نشده باشد، نودها نمایش داده می‌شوند. |
| 🙈 مخفی | بخش لوکیشن روی فاکتور نمایش داده نمی‌شود |

- **✏️ ثبت / ویرایش متن دستی**: متن را با چینش، بولد و ایموجی (حتی ایموجی پریمیوم) بفرستید. حداکثر **۳۰۰۰ کاراکتر**. متن جدید جای متن قبلی را می‌گیرد. پرچم‌ها را خودتان داخل متن بنویسید:

```text
🌍 لوکیشن‌ها:
🇩🇪 آلمان ⌁ 🇫🇮 فنلاند ⌁ 🇳🇱 هلند
```

- **👁 پیش‌نمایش**: متن را دقیقاً همان‌طور که روی فاکتور نمایش داده می‌شود برایتان می‌فرستد.
- **🧹 پاک کردن متن**: حذف متن دستی.

## 🧪 تنظیمات تست [#trial]

هر پنل جداگانه تعیین می‌کند که سرویس تست رایگان بدهد یا نه، و با چه حجم و مدتی.

| دکمه | توضیح |
|------|--------|
| 📥 حجم تست | به گیگابایت، اعشار مجاز است (مثلاً `0.5`). پیش‌فرض **۲ گیگ** |
| ⏰ زمان تست | تعداد روز (عدد صحیح). پیش‌فرض **۳ روز** |
| 🆓 ارائهٔ تست از این پنل / ❌ خاموش کردن تست این پنل | روشن یا خاموش کردن تست برای همین پنل |

- صفحه نشان می‌دهد که این پنل تست می‌دهد یا نه، و کدام پنل‌های دیگر هم تست می‌دهند.
- اگر چند پنل تست بدهند، کاربر هنگام دریافت تست پنل را انتخاب می‌کند. هر کاربر در کل فقط **یک** تست می‌گیرد. برای اجازهٔ دوباره از [🔄 ریست دریافت تست](/docs/admin/bulk-ops) استفاده کنید.
- دکمهٔ **دریافت تست** باید در [تنظیمات ربات](/docs/admin/bot-settings#purchase) روشن باشد. با **تایید شماره تست**، کاربر قبل از دریافت تست باید شمارهٔ ایرانی (`+98`) خودش را تایید کند.
- سرویس تست بعد از انقضا یا تمام شدن حجم بلافاصله حذف می‌شود.

## 🗑 حذف خودکار منقضی‌ها [#expired-delete]

سرویس‌های **پولی** این پنل، چند روز بعد از انقضا، از پنل و ربات حذف می‌شوند:

- **✅ روشن کردن / ❌ خاموش کردن حذف خودکار** (پیش‌فرض: روشن).
- **⏳ مهلت حذف**: بین **۱ تا ۳۶۵** روز، پیش‌فرض **۳ روز**.
- هنگام انقضا، کاربر پیامی می‌گیرد که اگر در این مدت تمدید نکند، سرویس حذف می‌شود. بعد از حذف هم پیام حذف و یک لاگ دریافت می‌کنید.
- اگر خاموش باشد، سرویس‌های منقضی برای همیشه می‌مانند تا کاربر یا شما حذفشان کنید.
- **سرویس‌های تست** شامل این تنظیم نیستند و بلافاصله بعد از انقضا حذف می‌شوند.

## 🧩 خرید دلخواه (حجم/زمان) [#custom-buy]

به‌جای پلن‌های آماده، کاربر حجم و تعداد روز را خودش وارد می‌کند و قیمت خودکار محاسبه می‌شود:

```text
قیمت = (گیگ × نرخ هر گیگ) + (روز × نرخ هر روز)
```

- **روشن/خاموش**، **💰 تنظیم نرخ هر گیگ** و **⏰ تنظیم نرخ هر روز** (به تومان).
- دکمه فقط وقتی برای کاربر فعال می‌شود که سوییچ روشن باشد و **هر دو نرخ بیشتر از صفر** باشند. «وضعیت نهایی» در همان صفحه این را نشان می‌دهد.
- بازهٔ پیش‌فرض: **۱ تا ۱۰۰۰ گیگ** و **۱ تا ۳۶۵ روز**. این بازه‌ها در پنل وب قابل تغییرند.

**مثال:** نرخ گیگ ۲,۰۰۰ و نرخ روز ۱,۰۰۰ تومان. ۵۰ گیگ ۳۰ روزه = ۱۰۰,۰۰۰ + ۳۰,۰۰۰ = **۱۳۰,۰۰۰ تومان**.

## 👥 خرید ظرفیت کاربر (نمایندگی) [#reseller-capacity]

نماینده‌های این پنل می‌توانند جدا از ظرفیت اصلی پلنشان، با پرداخت پول **سقف تعداد کاربر** (User Limit) ادمینشان را بالا ببرند.

- **روشن/خاموش** (پیش‌فرض: خاموش) و **💰 تنظیم قیمت هر کاربر** (پیش‌فرض **۲,۰۰۰ تومان**، باید بیشتر از صفر باشد).
- دکمهٔ «👥 خرید ظرفیت کاربر اضافه» در [دکمه‌های نمایندگی](#reseller-buttons) هم باید روشن باشد.

## ♾️ پلن‌های حجم اضافه / ⏰ پلن‌های زمان اضافه [#extra-plans]

تعرفه‌هایی که کاربر با دکمه‌های **خرید حجم** و **خرید زمان** روی سرویس فعالش می‌بیند.

- **➕ افزودن پلن حجم**: حجم به گیگ (اعشار مجاز) ← قیمت به تومان.
- **➕ افزودن پلن زمان**: تعداد روز ← قیمت به تومان.
- با زدن روی هر پلن: **✏️ ویرایش حجم/مدت**، **✏️ ویرایش قیمت**، **🎨 تنظیم دکمه نمایش** و **🗑 حذف پلن**.
- پلن‌ها از کوچک به بزرگ مرتب می‌شوند. تا وقتی پلنی تعریف نشده باشد، دکمهٔ خرید حجم یا زمان برای این پنل نمایش داده نمی‌شود.
- متن پیش‌فرض دکمه‌ها `{gig} گیگ — {price} تومان` و `{days} روز — {price} تومان` است. در **🎨 تنظیم دکمه نمایش → ✏️ متن دکمه** می‌توانید متن دلخواه با همین جای‌نگهدارها بنویسید، مثلاً `🔥 {gig} گیگ فقط {price}`. با `/skip` به متن پیش‌فرض برمی‌گردد. رنگ، آیکون پریمیوم و **♻️ ریست تنظیمات نمایش** هم آنجاست.

## ➕ لینک تانل / 🔄 حذف لینک تانل [#tunnel]

اگر برای پنل یک دامنه یا آی‌پی تانل‌شده (مثلاً سرور ایران) دارید، آدرسش را بفرستید، مثل `https://tunnel.example.com`. ربات یک لینک ساب جایگزین با همین آدرس می‌سازد و بسته به [🔗 لینک ساب](#sub-link) نشانش می‌دهد. وقتی لینک تانل تنظیم شده باشد، دکمه به **🔄 حذف لینک تانل** تبدیل می‌شود.

## 🔗 مسیر ورود ادمین [#admin-login-path]

برای نماینده‌ها مهم است. آدرس ورود به پنل که برای نماینده ارسال می‌شود از این مسیر ساخته می‌شود. اگر API پنل روی `https://domain.com` است ولی صفحهٔ ورود روی `https://domain.com/admin`، فقط `admin` را بفرستید. برای پاک کردن، `-` بفرستید.

## 📖 آموزش دکمه‌های تنظیمات پنل [#help]

یک راهنمای سه‌صفحه‌ای داخل خود ربات (با ◀️ صفحه قبل و صفحه بعد ▶️). این صفحه نسخهٔ کامل‌تر و به‌روزتر همان راهنماست.

## ❌ حذف پنل [#delete]

بعد از پیام تایید (`⚠️ این عملیات غیرقابل بازگشت است!`)، با **✅ بله، حذف کن** پنل و همهٔ تنظیماتش از دیتابیس ربات حذف می‌شود. خود پنل پاسارگارد و کاربرانش دست نمی‌خورند. اگر فقط می‌خواهید فروش را متوقف کنید، به‌جای حذف از [⚡ فعال‌سازی پنل](#enable) استفاده کنید.
