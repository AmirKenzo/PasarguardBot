از مسیر **پنل مدیریت → 📝 مدیریت لاگ‌ها** مقصد ارسال هر نوع لاگ را مشخص می‌کنید (کانال یا سوپرگروه با تایپک).

برای بکاپ دیتابیس و ریستور، صفحهٔ جداگانهٔ [بکاپ و ریستور](/docs/admin/backup-restore) را ببینید. کانال **🗄 بکاپ ربات** فقط مقصد ارسال فایل ZIP است.

---

## انواع لاگ

| دکمه | کاربرد |
|------|--------|
| 💳 کارت به کارت دستی | لاگ واریز کارت‌به‌کارت دستی |
| 💱 واریزی ارزی | لاگ پرداخت ارزی |
| 🏢 لاگ نمایندگی‌ها | رویدادهای نمایندگی |
| 📋 سایر لاگ‌ها | لاگ‌های عمومی/سایر |
| 🗄 بکاپ ربات | ارسال فایل ZIP بکاپ |
| 📦 کانال آپدیت برنامه‌ها | فایل‌ها و آپدیت برنامه‌ها |

---

## تنظیم مقصد

برای هر نوع لاگ:

1. نوع لاگ را انتخاب کنید.
2. نوع مقصد را بزنید:
   - **📢 کانال** — آیدی عددی کانال (معمولاً با `-` شروع می‌شود، مثل `-1001234567890`)
   - **👥 سوپرگروه با تایپک** — آیدی گروه یا لینک پیام داخل تایپک
3. آیدی/لینک را ارسال کنید تا ذخیره شود.

ربات باید در آن کانال/گروه ادمین باشد تا بتواند پیام بفرستد.

### ست همه با یک آیدی

**⚡ ست همه لاگ‌ها با یک آیدی** همان مقصد را برای **همه** انواع لاگ یکجا ست می‌کند.

### وضعیت

**📊 وضعیت لاگ‌ها** نشان می‌دهد کدام نوع‌ها ست شده‌اند و کدام نه.

---

## نکته برای بکاپ

بدون ست کردن کانال **🗄 بکاپ ربات**، دکمهٔ بکاپ در ربات فایل ارسال نمی‌کند. بعد از ست کانال، از [بکاپ و ریستور](/docs/admin/backup-restore) بکاپ بگیرید.
