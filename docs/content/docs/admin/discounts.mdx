## انواع کد [#types]

| نوع | دکمه | چه کسی می‌تواند استفاده کند | کد |
|------|------|-----------------------------|-----|
| عمومی | 🌍 عمومی | همهٔ کاربران | خودکار ساخته می‌شود |
| پرایوت | 💎 پرایوت | فقط **یک کاربر** با آیدی عددی مشخص | خودکار ساخته می‌شود |
| سفارشی | 🛠 کد سفارشی | بعد از نوشتن کد، عمومی یا پرایوت بودنش را انتخاب می‌کنید | خودتان می‌نویسید (مثلاً `YALDA`) |

کدها همیشه با **حروف بزرگ** ذخیره می‌شوند (`yalda` به `YALDA` تبدیل می‌شود). به کاربران بگویید کد را با حروف بزرگ وارد کنند، یا از [لینک دیپ](#deep-link) استفاده کنید.

## ساخت کد [#create]

<Steps>
<Step>

### نوع

**🪄 ساخت کدتخفیف** را بزنید و نوع را انتخاب کنید.
- **🛠 کد سفارشی**: اول کد دلخواه را بفرستید، بعد دوباره عمومی یا پرایوت را انتخاب کنید.
- **💎 پرایوت**: آیدی عددی کاربر را بفرستید.

</Step>
<Step>

### مدت اعتبار

یکی از گزینه‌های آماده را انتخاب کنید: ۱، ۳، ۶، ۱۲ و ۲۴ ساعت، یا ۱ تا ۷، ۳۰، ۶۰، ۹۰، ۱۸۰ و ۳۶۵ روز. با **🎯 دلخواه** هم عدد بفرستید:
- `7` یعنی ۷ روز
- `12h` یعنی ۱۲ ساعت

</Step>
<Step>

### سقف استفاده

تعداد **کل** دفعاتی که کد می‌تواند استفاده شود (بین همهٔ کاربران): ۱، ۲، ۳، ۵، ۱۰، ۱۵، ۲۵، ۵۰، ۱۰۰، ۲۰۰، ۵۰۰، ۱۰۰۰ یا **🎯 دلخواه**.

</Step>
<Step>

### درصد تخفیف

۵٪ تا ۱۰۰٪ از دکمه‌ها، یا **🎯 دلخواه** (عدد ۱ تا ۱۰۰).

</Step>
</Steps>

بعد از ساخت، خلاصهٔ کد همراه با **لینک دیپ** آن نمایش داده می‌شود. اگر کد تکراری باشد، پیام `❌ خطا در ساخت کد (احتمالاً تکراری است)` را می‌گیرید.

## لینک دیپ و تخفیف ماندگار [#deep-link]

هر کد یک لینک دارد:

```text
https://t.me/YourBot?start=discount_CODE
```

وقتی کاربر روی این لینک بزند، کد **روی حسابش ست می‌شود** و پیام «🎉 کد تخفیف روی حساب شما فعال شد!» را می‌گیرد. از آن به بعد، قیمت‌ها با همین تخفیف محاسبه می‌شوند و لازم نیست کد را دوباره وارد کند. کد ست‌شده در پروفایل کاربر هم نمایش داده می‌شود.

- فقط کدهایی که **تاریخ انقضا** دارند با لینک فعال می‌شوند. همهٔ کدهایی که از ربات ساخته می‌شوند تاریخ انقضا دارند.
- ست‌شدن تا پایان اعتبار کد باقی می‌ماند.
- لینک را در کانال، استوری یا کمپین تبلیغاتی بگذارید تا تخفیف فقط برای کسانی که از آن لینک می‌آیند فعال شود.

## کد کجا اعمال می‌شود؟ [#where]

| مسیر | تخفیف اعمال می‌شود؟ |
|-------|----------------------|
| خرید سرویس | ✅ |
| تمدید سرویس | ✅ |
| خرید نمایندگی با پلن **ثابت** | ✅ |
| خرید حجم اضافه / زمان اضافه | ❌ |
| شارژ کیف پول (افزایش موجودی) | ❌ |

هر بار استفادهٔ موفق یکی از سقف استفاده کم می‌کند. اگر خرید بعد از رزرو کد شکست بخورد، آن یک بار استفاده برمی‌گردد. پیام‌های خطای کاربر شامل «کد تخفیف منقضی شده است.»، «تعداد دفعات استفاده از این کد تخفیف تمام شده است.» و «این کد تخفیف برای شما معتبر نیست.» (کد پرایوت کاربر دیگر) است.

## 🎛 لیست و ویرایش کد [#edit]

لیست کدها ۱۰ تا ۱۰ تا نمایش داده می‌شود. با زدن روی هر کد، جزئیاتش (درصد، نوع، کاربر، استفاده، اعتبار، تعداد کاربرانی که کد روی حسابشان ست شده و لینک دیپ) و این گزینه‌ها را می‌بینید:

| دکمه | کار |
|------|-----|
| ✏️ تغییر کد | نام جدید برای کد (لینک دیپ هم عوض می‌شود) |
| 💸 تغییر درصد | ۱۰ تا ۵۰٪ یا دلخواه (۱ تا ۱۰۰) |
| 🔢 سقف استفاده | سقف جدید (بیشتر از صفر) |
| ♻️ ریست استفاده | صفر کردن تعداد استفاده |
| 🌍 عمومی / 💎 پرایوت | تغییر نوع |
| 👤 تغییر کاربر | آیدی عددی کاربر جدید. با فرستادن `0`، کد عمومی می‌شود |
| ⏳ تمدید اعتبار | ۱، ۶ و ۲۴ ساعت، ۱، ۷ و ۳۰ روز، یا **🎯 تمدید دلخواه** (`7` یا `6h`) |
| 🗑 حذف کدتخفیف | حذف کد |

## 📊 آمارگیری کدهای تخفیف [#stats]

یک گزارش کامل:

- **🗂 نمای کلی**: کل کدها، فعال، غیرفعال (منقضی‌شده، سقف پر، انقضای نزدیک در ۷ روز آینده)
- **🏷 دسته‌بندی**: تعداد عمومی و پرایوت
- **📈 مصرف و استفاده**: کل دفعات استفاده، ظرفیت کل و باقی‌مانده، نرخ مصرف، کدهایی که هرگز استفاده نشده‌اند و میانگین درصد تخفیف
- **🔗 ست دیپ‌لینک**: تعداد کاربرانی که کدی روی حسابشان ست شده و تعداد هر کد
- پراستفاده‌ترین کد، ۵ کد برتر، بیشترین درصد تخفیف، و جدیدترین و قدیمی‌ترین کد

با **🔄 بروزرسانی آمار** گزارش تازه می‌شود.
