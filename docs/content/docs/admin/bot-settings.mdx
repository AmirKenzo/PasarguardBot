بخش **تنظیمات ربات** هاب کنترل قابلیت‌هاست.

## کنترل‌های اصلی

وضعیت ربات، وضعیت فروش، خرید تک‌پنل، قفل کانال، ری‌اکشن استارت، محدودیت IP درگاه

## پرداخت‌ها

دکمه کارت دستی، دکمه درگاه ارزی، درخواست شماره برای کارت‌به‌کارت

## خرید و تمدید

خرید زمان، افزایش حجم، تمدید سرویس، دریافت تست، تایید شماره تست، پرداخت مستقیم خرید/تمدید

## نمایندگی

روشن/خاموش کردن فروش نمایندگی

## دکمه‌های منوی اصلی

پروفایل، راهنما، پشتیبانی، تنظیمات پیشرفته

## دکمه‌های صفحه سرویس

QR، ساب، لینک‌های دیگر، کلاینت‌ها، نمودار، تغییر/کپی لینک، انتقال، اطلاعات، حذف سرویس
