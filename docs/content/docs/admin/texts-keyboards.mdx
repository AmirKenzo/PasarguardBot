تقریباً همهٔ پیام‌های مهم ربات و دکمه‌های منوها را بدون دست زدن به کد می‌توانید به سلیقهٔ برند خودتان تغییر دهید.

| ابزار | مسیر | چه چیزی را عوض می‌کند |
|-------|------|----------------------|
| 📝 متن‌های ربات | **پنل مدیریت → 📝 متن‌های ربات** | متن پیام‌ها (استارت، خرید، اطلاعات سرویس، پرداخت، تمدید و…) |
| ⌨️ مدیریت دکمه‌های کیبورد | **پنل مدیریت → ⌨️ مدیریت دکمه‌های کیبورد** | متن، رنگ و آیکون ایموجی پریمیوم دکمه‌ها |

<Callout type="info" title="پنل تحت وب">
هر دو ویرایشگر در [پنل تحت وب](/docs/webapp/admin-panel) هم هستند. **چیدمان دکمه‌های منوی اصلی** (کدام دکمه در کدام ردیف باشد) فقط از پنل تحت وب و با کشیدن و رها کردن (Drag & Drop) قابل تغییر است.
</Callout>

## 📝 متن‌های ربات [#texts]

### بخش‌ها [#sections]

بعد از زدن دکمه، لیست بخش‌ها (۸ بخش در هر صفحه) نمایش داده می‌شود:

| بخش | نمونهٔ متن‌های داخل آن |
|-----|------------------------|
| 🚀 پیام استارت | پیام استارت، پیام ورود به اپلیکیشن |
| 🔑 سرویس‌های من | متن معرفی، پیام عدم وجود سرویس، دکمه خرید سرویس، **متن اطلاعات سرویس** |
| 🛍 خرید سرویس | معرفی خرید، انتخاب حجم پنل، انتخاب مدت، خرید دلخواه (حجم و زمان)، وارد کردن نام کاربری، نام تکراری، تأیید خرید، موفقیت خرید، تحویل کانفیگ تست، تأیید خرید با کد تخفیف |
| 💰 افزایش موجودی | معرفی افزایش موجودی، پیام‌های کسری و کمبود موجودی، پیام‌های پرداخت مستقیم |
| 💳 کارت به کارت | اطلاعات واریز، درخواست مبلغ و رسید، تایید/رد تراکنش، خطاهای مبلغ، عدم تطابق کارت |
| 💵 پرداخت ارزی | خطای بازه مبلغ، خطای ورودی غیرعددی |
| 🔔 اطلاع‌رسانی | اطلاع‌رسانی اتمام حجم |
| 🔄 تمدید سرویس | متن مراحل اول، دوم، نهایی و موفقیت تمدید |
| 🏢 نمایندگی | لیست نمایندگی‌های من، نبودن نمایندگی، انتخاب پنل و پلن |
| 📝 سایر | متن راهنما، **متن پشتیبانی**، متن تنظیمات پیشرفته، متن گزارش خرید در کانال |
| 🔲 رزرو 1 تا 3 | خالی؛ برای متن‌های آینده |

### ویرایش یک متن [#edit]

<Steps>
<Step>

### انتخاب بخش و متن

یک بخش را بزنید، سپس روی `✏️ عنوان متن` بزنید.

</Step>
<Step>

### انتخاب زبان

بین `🇮🇷 فارسی` و `🇬🇧 English` انتخاب کنید. در همین صفحه لیست پلیس‌هولدرهای آن متن هم نمایش داده می‌شود.

<Callout type="info">
ربات به فارسی با کاربران صحبت می‌کند؛ برای تغییر چیزی که کاربران می‌بینند، نسخهٔ **فارسی** را ویرایش کنید.
</Callout>

</Step>
<Step>

### دیدن متن فعلی

متن فعلی (یا پیام `⚠️ برای این زبان هنوز متنی ست نشده است.` یعنی متن پیش‌فرض ربات استفاده می‌شود)، وضعیت بنر و پلیس‌هولدرها نمایش داده می‌شود. دکمه‌ها: `🖼️ تغییر لینک بنر`، `🔄 ریست به پیش‌فرض` و `🔙 بازگشت`.

</Step>
<Step>

### ارسال متن جدید و تایید

متن جدید را در چت بفرستید. ربات **پیش‌نمایش** آن را دقیقاً با فرمت نهایی نشان می‌دهد؛ `✅ بله، ذخیره کن` یا `❌ خیر، لغو` را بزنید.

</Step>
</Steps>

### پلیس‌هولدرها [#placeholders]

پلیس‌هولدر یک کلمه داخل آکولاد است که ربات هنگام ارسال با مقدار واقعی جایگزین می‌کند. هر متن پلیس‌هولدرهای خودش را دارد (در صفحهٔ ویرایش لیست می‌شوند) و متن‌هایی هم هستند که پلیس‌هولدر ندارند. مثلاً **متن اطلاعات سرویس**:

| پلیس‌هولدر | مقدار |
|-----------|-------|
| `{status}` | وضعیت سرویس |
| `{config_name}` / `{service_code}` | اسم کانفیگ / کد سرویس |
| `{plan_name}` | نام پلن |
| `{used_volume}` / `{remaining_volume}` / `{total_volume}` | حجم مصرفی / باقی‌مانده / کل |
| `{usage_progress}` | نوار درصد مصرف |
| `{expiry_date}` | تاریخ انقضا |
| `{subscription_url}` | لینک سابسکریپشن |
| `{ip_limit}`، `{last_connection}`، `{reset_info}` و… | سایر جزئیات (اختیاری) |

نمونه:

```text
🔷 سرویس: {config_name}
📊 مصرف: {used_volume} از {total_volume}
{usage_progress}
⏳ انقضا: {expiry_date}
🔗 {subscription_url}
```

<Callout type="warn">
نام پلیس‌هولدر را دقیقاً همان‌طور که در لیست نوشته شده (با آکولاد و حروف انگلیسی کوچک) بنویسید؛ پلیس‌هولدر غلط به همان شکل خام برای کاربر نمایش داده می‌شود.
</Callout>

### فرمت و ایموجی پریمیوم [#formatting]

لازم نیست کد فرمت بنویسید: متن را **در خود تلگرام** فرمت کنید (بولد، ایتالیک، لینک، کد، اسپویلر و…) و بفرستید؛ ربات فرمت را حفظ می‌کند. ایموجی‌های **پریمیوم** هم اگر حساب شما تلگرام پریمیوم داشته باشد، همان‌طور ذخیره و برای کاربران نمایش داده می‌شوند.

برای چند فرمت خاص می‌توانید این علامت‌ها را دستی بنویسید:

| علامت | نتیجه |
|-------|-------|
| `^q^متن^q^` | نقل‌قول (Quote) |
| `^qc^متن^qc^` | نقل‌قول جمع‌شونده (Expandable) |
| `^sp^متن^sp^` | اسپویلر |
| `[😀](emoji/5368324170671202286)` | ایموجی پریمیوم با شناسهٔ عددی |

### بنر [#banner]

با `🖼️ تغییر لینک بنر` یک لینک (مثلاً لینک یک تصویر) برای آن متن ذخیره می‌کنید؛ برای حذف بنر یک پیام خالی/فاصله بفرستید. موقعیت بنر (بالا یا پایین) در صفحهٔ ویرایش نمایش داده می‌شود و از ویرایشگر متن‌های پنل تحت وب قابل انتخاب است.

<Callout type="info">
لینک بنر همراه متن ذخیره می‌شود، ولی در نسخهٔ فعلی ربات، پیام‌هایی که برای کاربر ارسال می‌شوند بنر را نمایش نمی‌دهند. اگر تصویر می‌خواهید، فعلاً لینک آن را داخل خود متن بگذارید.
</Callout>

### 🔄 ریست به پیش‌فرض [#reset]

متن سفارشی آن زبان را پاک می‌کند تا ربات دوباره از متن پیش‌فرض استفاده کند. اگر متنی سفارشی نشده باشد، پیام `⚠️ متن یافت نشد یا قبلاً از پیش‌فرض استفاده می‌کند` می‌آید.

## ⌨️ مدیریت دکمه‌های کیبورد [#keyboard]

دکمه‌ها در **۵ صفحه** دسته‌بندی شده‌اند و با `➡️ صفحه بعدی` / `⬅️ صفحه قبلی` جابه‌جا می‌شوید. هر دکمه در این لیست با ظاهر فعلی خودش (متن و رنگ) نمایش داده می‌شود.

| صفحه | دکمه‌ها |
|------|---------|
| ۱ — منوی اصلی | 🎁 دریافت تست، 🔑 سرویس های من، 🛍 خرید سرویس، 📋 نمایندگی‌های من، 🏢 خرید پنل نمایندگی، 🙍 پروفایل من، 💰 افزایش موجودی، ☎️ پشتیبانی، 🔋 وضعیت سرویس ها، 📚 راهنما، ⚙️ تنظیمات پیشرفته، ⚙️ پنل مدیریت، و دکمه‌های مینی‌اپ (🚀 ورود به اپلیکیشن، 🚀 باز کردن اپلیکیشن) |
| ۲ — سرویس‌های من | تغییر لینک/ساب، کپی لینک، نمایش اطلاعات بیشتر، حجم اضافه، تمدید زمان، تمدید سرویس، QR، واگذاری، لینک‌های دیگر، کلاینت‌ها، نمودار مصرف، حذف کانفیگ، بازگشت، دکمه‌های تأیید تمدید و صفحه‌بندی لینک‌های دیگر |
| ۳ — افزایش موجودی | پرداخت ارزی، کارت به کارت، دعوت دوستان، بازگشت، شارژ غیرفعال، زیرمنوی ارزی (TRX، USDT، TON، بازگشت)، ارسال رسید و انصراف کارت به کارت |
| ۴ — خرید سرویس | انصراف، بازگشت، تأیید خرید، کد تخفیف، افزایش موجودی (فاکتور)، اسم پیشفرض، تغییر مجدد نام، حجم و زمان دلخواه، خرید (بدون سرویس) |
| ۵ — نمایندگی | نمایش رمز، تغییر رمز، فعال/غیرفعال‌سازی پنل، تمدید، گزارش مصرف، محدودیت مصرف، تنظیم/حذف سقف، حذف نمایندگی، خرید ظرفیت کاربر، نام تصادفی، تأییدهای حذف و تغییر رمز |

| دکمه | کار |
|------|-----|
| ✏️ متن دکمه | متن جدید را بفرستید؛ بلافاصله ذخیره می‌شود |
| آبی / سبز / قرمز / — | رنگ دکمه؛ `—` یعنی بدون رنگ |
| 🖼 آیکون ایموجی پریمیوم | یک **ایموجی پریمیوم** بفرستید (یا شناسهٔ عددی آن یا `emoji/ID`). ایموجی معمولی قبول نمی‌شود. `/skip` آیکون را حذف می‌کند |
| 🧹 حذف آیکون | حذف آیکون فعلی |

<Callout type="warn" title="نکته‌ها">
- رنگ و آیکون دکمه‌ها فقط در نسخه‌های جدید تلگرام نمایش داده می‌شوند؛ در نسخه‌های قدیمی دکمه عادی دیده می‌شود.
- ربات دکمه‌ها را با **متن** آن‌ها تشخیص می‌دهد. بعد از تغییر متن یک دکمهٔ منوی اصلی، کاربرانی که کیبورد قدیمی را دارند با `/start` منوی جدید را می‌گیرند.
- دو دکمه را هم‌نام نکنید.
</Callout>
