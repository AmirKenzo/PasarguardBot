## متن‌های ربات

ویرایش متن‌های بخش‌های مختلف: استارت، سرویس‌های من، خرید، موجودی، کارت‌به‌کارت، ارزی، اطلاع‌رسانی، تمدید، نمایندگی و سایر.

## مدیریت دکمه‌های کیبورد

سفارشی‌سازی متن/استایل/آیکون دکمه‌های منوی اصلی، سرویس‌های من، موجودی و خرید.
