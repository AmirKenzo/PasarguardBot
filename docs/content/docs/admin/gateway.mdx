بخش **تنظیمات درگاه** برای مدیریت روش‌های شارژ است.

## امکانات اصلی

- افزودن / حذف / انتخاب کارت فعال
- نمایش کارت، کارت تصادفی، تایید خودکار
- قوانین تایید خودکار
- محدودیت مبلغ کارت دستی و واریز ارزی
- حداقل شارژ نمایندگی
- بونوس شارژ دستی / ارزی
- مدیریت کیف پول‌ها: TRX / USDT / TON

صفحهٔ کاربر مرتبط: [افزایش موجودی](/docs/user/balance)
