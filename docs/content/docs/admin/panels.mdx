بخش **منوی پنل‌ها** برای اتصال پنل پاسارگارد و تنظیم فروش است.

## لیست

- وضعیت پنل‌ها
- افزودن پنل جدید
- ورود به جزئیات هر پنل

## جزئیات پنل

| موضوع | مثال |
|--------|------|
| فروش | فعال‌سازی، خرید سرویس، نمایندگی |
| هویت | نام، ورود، گروه، محدودیت کاربر |
| دکمه‌ها | دکمه‌های «سرویس من» و نمایندگی |
| لینک | ساب، لینک تکی، پیشوند نود |
| تست | تنظیمات دریافت تست |
| پلن اضافه | حجم اضافه / زمان اضافه |
| دیگر | تانل، مسیر ادمین، آموزش، حذف پنل |
