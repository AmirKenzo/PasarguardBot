## لینک‌های آماده

ساخت و نمایش دیپ‌لینک‌های آماده برای ورود سریع به بخش‌های ربات.

## آپدیت برنامه‌ها

مدیریت لیست کلاینت‌های راهنما:

- افزودن از GitHub
- افزودن متنی
- بازگردانی پیش‌فرض‌ها

این برنامه‌ها در [راهنما](/docs/user/help-support) به کاربر نشان داده می‌شوند.
