## فیلدها [#fields]

| فیلد | توضیح |
|------|-------|
| 👤 شناسه کاربری | **آیدی عددی تلگرام** شما. برای دریافت سرویس واگذارشده یا پیگیری پشتیبانی همین عدد را بدهید |
| 👥 تعداد زیرمجموعه ها | تعداد کسانی که با [لینک دعوت](/docs/user/referral) شما وارد ربات شده‌اند |
| 💰 موجودی | موجودی کیف پول به تومان؛ برای شارژ به [افزایش موجودی](/docs/user/balance) بروید |
| 📞 شماره تلفن | شماره‌ای که برای کارت به کارت یا تست تأیید کرده‌اید؛ اگر ثبت نکرده باشید `ثبت نشده` نوشته می‌شود |
| 🕒 تاریخ عضویت | تاریخ شمسی اولین استارت ربات |
| 🎁 کدتخفیف | کد تخفیف فعال یا اختصاصی شما (پایین را ببینید) |

## نمایش کد تخفیف [#discount]

بسته به وضعیت شما یکی از این‌ها نمایش داده می‌شود:

<Tabs items={['تخفیف موقت فعال', 'کد اختصاصی', 'بدون کد']}>
<Tab value="تخفیف موقت فعال">

اگر با لینک `discount_...` یک کد **عمومی** روی حسابتان فعال کرده باشید:

```text
━━━━━━━━ 🎟 کد تخفیف فعال (موقت) ━━━━━━━━
📌 کد: SUMMER
💸 درصد: 20%
⏳ انقضا: 1404/04/01 (12 روز دیگر)
🔗 لینک دعوت دیگران:
https://t.me/YourBot?start=discount_SUMMER
```

این تخفیف روی خرید سرویس‌های جدید خودکار اعمال می‌شود و می‌توانید لینکش را برای دیگران هم بفرستید.

</Tab>
<Tab value="کد اختصاصی">

اگر فروشنده یک کد مخصوص شما ساخته باشد، مشخصاتش نمایش داده می‌شود: کد، درصد تخفیف، نوع (`💎 پرایوت 💎` یا `🌍 عمومی 🌍`)، تعداد استفاده (برای کدهای پرایوت، مثل `1/3`) و تاریخ انقضا. این کد را هنگام خرید با دکمه 🎉 اعمال کد تخفیف وارد کنید.

</Tab>
<Tab value="بدون کد">

```text
🎁کدتخفیف: ❌شما کدتخفیف اختصاصی ندارید
```

</Tab>
</Tabs>

## نکته‌ها

- نمایش دکمه 🙍 پروفایل من در منو با فروشنده است و ممکن است خاموش باشد؛ دستور `/mywallet` در هر حال پروفایل را نشان می‌دهد.
- در حالت منوی شیشه‌ای، زیر پروفایل دکمه **🏠 بازگشت** هست.
- شماره تلفن از داخل پروفایل قابل تغییر نیست؛ اگر لازم است عوض شود با [پشتیبانی](/docs/user/help-support) تماس بگیرید.
