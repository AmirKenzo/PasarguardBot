دکمهٔ **سرویس‌های من** لیست کانفیگ‌های کاربر را نشان می‌دهد.

## اکشن‌های رایج

| دکمه | کاربرد |
|------|--------|
| تغییر لینک / ساب / کپی لینک | مدیریت لینک اتصال |
| نمایش اطلاعات بیشتر | جزئیات سرویس (webview) |
| حجم اضافه / تمدید زمان / تمدید سرویس | افزایش یا تمدید |
| دریافت Qrcode | ساخت QR |
| واگذاری کانفیگ | انتقال به کاربر دیگر |
| نمایش لینک‌های دیگر | لینک‌های اضافه و دریافت همه |
| نمایش کلاینت‌ها | لیست کلاینت‌های متصل |
| نمودار مصرف | آمار مصرف |
| حذف کانفیگ | فقط برای سرویس‌های منقضی/محدود/غیرفعال |

> نمایش هر دکمه به تنظیمات پنل و تنظیمات سراسری ادمین بستگی دارد.
