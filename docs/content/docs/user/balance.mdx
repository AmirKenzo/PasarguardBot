دکمهٔ **افزایش موجودی** روش‌های شارژ کیف پول را نشان می‌دهد.

| روش | توضیح |
|-----|--------|
| پرداخت ارزی | TRX / USDT / TON |
| کارت به کارت | ارسال رسید و تایید (دستی یا خودکار) |

اگر هیچ روشی فعال نباشد، پیام غیرفعال بودن شارژ نمایش داده می‌شود.

جزئیات تنظیم درگاه: [تنظیمات درگاه](/docs/admin/gateway)
