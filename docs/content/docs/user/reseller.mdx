وقتی فروش نمایندگی فعال باشد این دکمه‌ها در منوی اصلی ظاهر می‌شوند:

- خرید پنل نمایندگی
- نمایندگی‌های من

## خرید

انتخاب پنل → پلن نمایندگی → نام کاربری → تایید (با امکان کد تخفیف)

## مدیریت نمایندگی

| دکمه | کاربرد |
|------|--------|
| نمایش رمز ورود | دیدن پسورد |
| تغییر رمز عبور | ریست پسورد |
| فعال / توقف | وضعیت اکانت |
| تمدید | تمدید پلن |
| گزارش مصرف | آمار |
| حذف | حذف نمایندگی |
