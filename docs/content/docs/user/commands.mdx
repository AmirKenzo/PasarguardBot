علاوه بر دکمه‌های منو، می‌توانید با فرستادن چند **دستور** یا باز کردن **لینک مستقیم** یک بخش خاص را سریع باز کنید.

## دستورهای کاربر [#user-commands]

| دستور | کار | معادل دکمه |
|-------|-----|------------|
| `/start` | شروع ربات و تازه کردن منوی اصلی | — |
| `/buy` | شروع خرید سرویس | 🛍 خرید سرویس |
| `/charge` | باز کردن روش‌های شارژ کیف پول | 💰 افزایش موجودی |
| `/myaccount` | نمایش لیست سرویس‌های شما | 🔑 سرویس های من |
| `/mywallet` | نمایش پروفایل و موجودی | 🙍 پروفایل من |
| `/help` | منوی راهنما و دانلود برنامه‌ها | 📚 راهنما |
| `/support` | ارسال پیام به پشتیبانی | ☎️ پشتیبانی |
| `/games` | منوی بازی‌ها (جایزه نقدی) | ندارد |
| `/dice` | انداختن سریع تاس شانس | ندارد |

<Callout type="info">
بازی‌ها دکمه‌ای در منو ندارند و فقط با `/games` و `/dice` باز می‌شوند. جزئیات در صفحه [بازی‌ها](/docs/user/games).
</Callout>

## دستورهای ادمین [#admin-commands]

این دستورها فقط برای ادمین‌های ربات کار می‌کنند و کاربر عادی پاسخی نمی‌گیرد:

| دستور | کار |
|-------|-----|
| `/panel` | باز کردن پنل مدیریت |
| `/webapp` | دکمه تست ورود به وب‌اپ از داخل تلگرام |
| `/ping` | بررسی سرعت پاسخ ربات (`Pong!` و زمان پاسخ) |

## لینک‌های مستقیم (start) [#deep-links]

لینک‌هایی به شکل زیر، ربات را باز می‌کنند و بلافاصله یک بخش خاص را نشان می‌دهند. فروشنده‌ها معمولاً این لینک‌ها را در کانال یا پست تبلیغاتی می‌گذارند.

```text
https://t.me/<نام‌کاربری-ربات>?start=<پارامتر>
```

| پارامتر | چه چیزی باز می‌شود |
|---------|---------------------|
| `start` | شروع مجدد و تازه کردن منوی ربات |
| `free` | مستقیم دریافت سرویس تست |
| `buy` | مستقیم شروع خرید سرویس |
| `charge` | مستقیم منوی افزایش موجودی |
| `ref_...` | لینک دعوت اختصاصی یک کاربر (در صفحه [دعوت دوستان](/docs/user/referral) ساخته می‌شود) |
| `discount_CODE` | فعال کردن کد تخفیف `CODE` روی حساب (پایین را ببینید) |
| `downloadhappandroid` | دانلود مستقیم برنامه Happ |
| `downloadv2rayngandroid` | دانلود مستقیم برنامه V2rayNG |
| `downloadhiddifyandroid` | دانلود مستقیم برنامه hiddify-app |
| `downloadv2raynpc` | دانلود مستقیم برنامه v2rayN (کامپیوتر) |
| `downloadnekoraywindows` | دانلود مستقیم برنامه Throne (Nekoray) |

نکته‌ها:

- اگر قفل کانال فعال باشد، لینک‌های `free`، `buy` و `charge` اول شما را به عضویت در کانال می‌فرستند و بعد کار می‌کنند.
- پارامتر ناشناخته یا قدیمی فقط منوی اصلی را باز می‌کند و مشکلی ایجاد نمی‌شود.

### لینک دعوت `ref_` [#ref-link]

لینک دعوت هر کاربر مخصوص خود اوست و یک امضای امنیتی دارد، پس نمی‌شود آن را دستی ساخت یا آیدی را در آن عوض کرد. این لینک فقط برای **کاربران جدید** کار می‌کند؛ اگر کسی که قبلاً ربات را استارت کرده با لینک دعوت وارد شود این پیام را می‌گیرد:

```text
⚠️ شما قبلاً عضو ربات هستید و نمی‌توانید از سیستم دعوت استفاده کنید.
```

### لینک کد تخفیف `discount_` [#discount-link]

با باز کردن لینکی مثل `?start=discount_SUMMER`، کد تخفیف `SUMMER` روی حساب شما **ذخیره** می‌شود و پیامی مثل این می‌آید:

```text
🎉 کد تخفیف روی حساب شما فعال شد!

🎟 کد: SUMMER
💸 درصد تخفیف: 20%
📋 نوع: 🌍 عمومی
⏳ اعتبار تا: ...

✅ از این به بعد قیمت‌ها با این تخفیف محاسبه می‌شوند و نیازی به وارد کردن مجدد کد نیست.
```

از این به بعد در هر خرید سرویس، تخفیف خودکار روی فاکتور اعمال می‌شود تا وقتی کد منقضی شود یا ظرفیتش تمام شود. توضیح بیشتر در [خرید سرویس — تخفیف ذخیره‌شده](/docs/user/buy#sticky-discount).

- فقط کدهایی که **تاریخ انقضا** دارند از طریق لینک فعال می‌شوند. برای کد بدون تاریخ انقضا پیام «فقط کدهای تخفیف موقت (دارای تاریخ انقضا) از طریق لینک قابل فعال‌سازی هستند.» می‌آید.
- اگر کد معتبر نباشد، دلیلش (مثلاً «کد تخفیف منقضی شده است.») نمایش داده می‌شود.

## لینک‌های آماده برای ادمین [#ready-links]

ادمین لازم نیست این لینک‌ها را دستی بسازد: در **پنل مدیریت → 🔗 لینک های آماده** لینک‌های اصلی (`start`، `free`، `buy`، `charge`) و لینک‌های دانلود برنامه‌ها با نام کاربری ربات خودتان، آماده کپی نمایش داده می‌شوند. لینک `discount_` هر کد تخفیف هنگام ساخت یا مشاهده همان کد در بخش [کدهای تخفیف](/docs/admin/discounts) داده می‌شود و لینک `ref_` را هر کاربر از بخش دعوت دوستان خودش می‌گیرد.
