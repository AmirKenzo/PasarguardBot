دکمهٔ **تنظیمات پیشرفته** برای شخصی‌سازی نمایش لیست سرویس‌ها و ابزارهای کمکی است.

## امکانات

- نمایش/مخفی کردن: کلمه اکانت، نام کانفیگ، حجم، نام پنل
- تعداد دکمه در هر ردیف / تعداد ردیف‌ها
- تبدیل متن به QR Code
