دکمهٔ **خرید سرویس** وقتی فروش روی حداقل یک پنل فعال باشد در منوی اصلی دیده می‌شود.

## جریان کار

1. انتخاب پنل
2. انتخاب گروه مدت / حجم (پلن)
3. وارد کردن نام کانفیگ (یا اسم پیش‌فرض ربات)
4. تایید خرید — در صورت نیاز اعمال کد تخفیف
5. اگر موجودی کافی نباشد، امکان هدایت به شارژ مستقیم

## نکات

- خرید تک‌پنل و وضعیت فروش از [تنظیمات ربات](/docs/admin/bot-settings) کنترل می‌شود.
- کد تخفیف در مرحله تایید قابل اعمال است.
