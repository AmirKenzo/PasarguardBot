**[Documentación completa (Persa)](https://amirkenzo.github.io/PasarguardBot/)**

## Instalación rápida (Linux)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AmirKenzo/PasarguardBot/main/scripts/pasarguardbot.sh)
```

Después de la instalación: `pasarguardbot`
